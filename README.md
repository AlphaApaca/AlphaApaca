## Selected Work

### [Environment-Aware Feasibility Planning for Local LLMs in MuJoCo](https://github.com/AlphaApaca/flexplan-mujoco-dissertation)

MSc dissertation project evaluating whether local LLM-generated robot plans are executable in their environment.

- Built a MuJoCo benchmark with **168 tasks**, **84 matched pairs**, and **7 controlled failure categories**.
- Implemented a deterministic feasibility verifier and a verifier-guided plan-repair pipeline.
- Evaluated **6 local models** across multiple conditions, producing **9,828 experiment records**.

`Python` `MuJoCo` `Ollama` `Qwen3` `Ministral 3`

### [V.I.S.O.R. — Autonomous Mobile Manipulation Robot](https://github.com/allanbissac/V.I.S.O.R.)

University team project integrating mapping, navigation, perception, and manipulation on a Leo Rover.

- Contributed mainly to navigation validation and tuning.
- Tested SLAM mapping/localization, Nav2 planners and costmaps, and return-to-start navigation.
- Supported integration and debugging in Gazebo and on the physical robot.

`ROS2` `Nav2` `SLAM Toolbox` `TF` `Gazebo` `Leo Rover`
